# v0.1.0 — first public preview

Independent QA worker for Freejira review tasks: GitHub PR evidence, configured local checks, Ollama assessment, durable state, retry handling and report deduplication.

Column changes and execution of untrusted repository code are disabled by default. macOS and Linux setup instructions are included.

Includes MIT license, English/Russian documentation, contribution and security guidance, example configuration and CI. This is an early release, without a stability or support SLA.
