# Security policy

Security fixes target the latest `main` and latest tagged release. Earlier versions are not maintained independently.

Report a suspected vulnerability using [GitHub private vulnerability reporting](https://github.com/a1231231123bc/freejira-qa/security/advisories/new). Include affected versions, minimal reproduction and impact. Use synthetic data and redact tokens. Do not publish exploit details or private data in a public issue. If private reporting is unavailable, open an issue asking for a private contact without technical details.

Do not assume this young project has received an independent security audit. Deployment and operational boundaries are documented in the README. Review changes before granting credentials or exposing a service publicly.
