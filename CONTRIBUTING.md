# Contributing

Thank you for helping improve freejira-qa. Bug reports, documentation, accessibility fixes and tests are welcome. English and Russian are both welcome.

1. Open an issue for a substantial behavior or architecture change before building it.
2. Fork the repository and create a focused branch from `main`.
3. Follow the development and test commands in the README. Use synthetic fixtures and an isolated local instance.
4. Add a regression test when changing correctness, access control, concurrency or retry behavior.
5. Submit a pull request describing the problem, final behavior, validation and remaining limitations. Include screenshots for UI changes.

Keep credentials, customer data, real videos, private repository diffs and generated QA reports out of issues and commits. Do not run checks against someone else's production workspace. Security issues go through the private process in [SECURITY.md](SECURITY.md).

By contributing, you agree that your contributions may be distributed under this repository's MIT license and that you have the right to submit them. Third-party notices must be preserved. There is no CLA.

Maintainers review changes before merging. Keep discussion respectful, specific and focused on the work; harassment and disclosure of private information are not acceptable. The project is maintained on a best-effort basis, without a support SLA.
